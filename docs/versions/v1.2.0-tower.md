# v1.2.0-tower — detector adapted to lookout-tower cameras (stage 2)

**Tag:** `v1.2.0-tower` → commit `d511635` · **Date:** 2026-09-24 · **Status:** frozen · **Not recommended for D-Fire-style scenes** (see known issues)

Stage-2 fine-tune of the v1.1.0 detector on real lookout-tower imagery, to close the domain gap found in v1.1.0. The context VLM is unchanged from v1.1.0.

## Known issues

- **Catastrophic forgetting:** sequential fine-tuning on smoke-only tower data erased D-Fire performance and the fire class entirely. Use for tower cameras only; v1.3.0 (joint training) is the planned fix.
