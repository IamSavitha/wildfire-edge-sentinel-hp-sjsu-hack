# v1.0.0-baseline — off-the-shelf models

**Tag:** `v1.0.0-baseline` → commit `d0bfc87` · **Date:** 2026-09-23 · **Status:** frozen reference

The "before" system: the full edge pipeline (cascade, severity rules, escalation, outbox) running **off-the-shelf models with no task-specific training**. Every later version is measured against this one.

## Configuration

- Serve: `zrt serve hf:Qwen/Qwen2.5-VL-7B-Instruct --label base7b --gpu-memory-fraction 0.45 -- --max-model-len=8192 --enable-prefix-caching`
- Runtime settings: `{"vlm_model": "base7b", "detector_weights": "yolov8s-worldv2.pt", "detector_classes": ["smoke", "fire"]}`
- YOLO-World needs its CLIP text encoder; run once while online so it is cached.

## Known issues

- The detector almost never reaches the 0.4 confidence gate on smoke, so the cascade rarely reaches the VLM.
- The base VLM never answers "unknown" (0/138) and calls controlled burns "wildland" (1/53 correct).
