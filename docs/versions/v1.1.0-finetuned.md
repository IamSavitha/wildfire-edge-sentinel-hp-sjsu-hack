## Configuration

- Serve base + adapter from one vLLM process:
  `zrt serve hf:Qwen/Qwen2.5-VL-7B-Instruct --label base7b --gpu-memory-fraction 0.45 -- --max-model-len=8192 --enable-prefix-caching --enable-lora --max-lora-rank=16 --lora-modules context=<path>/context`
- The zrt proxy routes only the label `base7b`; request the adapter on the backend socket: `vlm_base_url = unix:///opt/hp/zrt/run/vllm-base7b.sock`, `vlm_model = context`.
- Runtime settings: `{"vlm_model": "context", "vlm_base_url": "unix:///opt/hp/zrt/run/vllm-base7b.sock", "detector_weights": "models/smoke_yolo.pt"}`

## Known issues

- **Tower-domain gap:** detects only ~20% of lookout-tower smoke (small distant plumes) → addressed in v1.2.0.
- **Industrial stacks regressed** (54 → 38 of 66): the student over-uses "unknown"/"controlled burn" there.
- VLM accuracy is **agreement with the 32B teacher**, not ground truth.
