Edge cascade vs cloud: every image to a VLM

No images yet.

Edge: the detector runs on every image, the local VLM only on detections (on a ≤448 px crop), and only ALERT reports leave the device. Cost: $0 marginal API cost (Nano hardware and power not included); the edge pays uplink only, counting alerts sent and alerts queued to send when the link returns. Cloud baseline: every image uploaded and sent whole to a Qwen2.5-VL-class model at ≤1280 px, the same frame the edge VLM gets under “force”. Its image tokens are estimated with Qwen's resize rule; prompt and output tokens per call are the ones measured here. Passes whose VLM is not served run detector-only and are left out of both sides.

Network

While the link is down the edge still runs every model and holds ALERTs in the outbox. A cloud-only design has no model to run for those images.
